# qobjfile Manual

This manual contains 26 chapters covering qbfd, qld, command line tools, ISA metadata, formats, APIs, scripts, and extension points.

## Reading order

- Chapters 1–11 introduce the object model, format readers, archives, queries, and command line tools.
- Chapters 12–24 describe qld, linker scripts, layout, relocation, emission, and link modes.
- Chapters 25–26 cover verification and extension work.

The ISA progression is documented in Chapters 3, 10, 11, and 26. Processor descriptions live under `infobank/isa`; their grammar is specified by `infobank/isa.peg`, and the schema is in `infobank/schema.json`.
